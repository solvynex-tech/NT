# 实盘接入缺口与验收

当前具备研究和原生 IBKR 委托代码路径，尚不具备经过验证的无人值守实盘能力。能连接账户、生成订单或通过回测，都不能证明真实组合成交、策略盈利或故障后安全恢复。

## 1. 组合单生命周期：代码统一，券商验证待完成

`runtime/trading.py` 注册 NT 的 IBKR 数据与执行客户端；`margin.py` 用 IB API 做只读 what-if 查询。实际交易订单走 NT。Theta 数据通过官方 SDK 和 Actor 接入，不是 NT 的原生 Theta 适配器。

须验证三腿 1:-2:1 BAG 的合约资格、方向、负权利金限价、SMART 路由、价格步长，以及真实开仓、撤单和市价平仓回报。覆盖部分成交、拒单、撤单与成交交错，确认组合数量和逐腿实际持仓一致。

回放与 live 现共用 `OrderManagementConfig`：默认中点限价、120 秒开仓超时、撤单确认后冷却 60 秒、最多 3 次尝试；平仓超时和最大尝试次数也受限。撤单确认超时不释放额度、不假定已撤。迟到的成交与组合数量不符时冻结新订单，要求对账。已成交身份不重复开仓。

回放的延迟、触价概率、有限合成盘口与 IOC 分片属于研究模型，不套到 IBKR 实盘。live 使用 NT BAG 限价开仓 / 市价退出；这条代码路径尚无本次实际委托验证。

验收：先在 paper 完成流程测试；经明确授权后再用最小规模真实委托校准成交。IBKR paper 对组合交易有限制，不能单独验证实盘成交质量。[官方说明](https://www.ibkrguides.com/clientportal/aboutpapertradingaccounts.htm)

## 2. 重启恢复：持久意图与原生证据核验已实现

节点启用 NT reconciliation、24 小时回看与全部活动订单查询。SQLite 原子提交组合身份、待确认订单、已完成身份、重试和退出路径标记；独立账户 SQLite 锁防止两个 QWORK 交易进程同时管理同一账户。状态在 `data/private/trading/<mode>/<account>/<symbol>.sqlite3`，不同报告目录不会创建另一份交易意图。

启动先验证真实账户回报，再从 NT 原生订单已成交数量推导组合数量，核验所属策略、合约、方向和逐腿净持仓。共享腿按各组合数量聚合后对账，不用净腿数量猜组合。原生成交证据缺失、未知活动订单、账户其他持仓或上一交易日残余暴露都会阻止恢复。恢复前不发送开仓或猜测数量平仓。当前适用于专用账户；不自动接管外部策略仓位。

SQLite 保存的是策略意图，NT / 券商仍是成交与资金权威。委托前、状态事件后及每秒保存；崩溃前最后一秒的报价路径标记可能未提交。24 小时回看不保证券商能返回全部已成交 BAG 历史，证据缺失时必须人工核验，不能声称无人值守恢复完成。

验收：在开仓待成交、部分成交、平仓待成交三个阶段分别强制中断并重启；确认不重复下单、不漏管仓位，重复成交回报不重复记账。日切也需明确处理完成组合集合。

## 3. 账户风险：入口保护已实现，真实数量保证金待补齐

已有组合最大亏损预算、并发数量和报价时效过滤。新增账户亏损阈值、净值峰值回撤、可用资金缓冲、数据时效与连续拒单限制。基于已报告的 USD `NetLiquidation` / `AvailableFunds`，缺字段或过期就禁止开仓，不以现金余额代替净值。默认亏损 500 USD、回撤 1,000 USD、资金缓冲 100 USD、账户数据最长 300 秒、拒单最多 3 次，需按账户自行配置。

当日亏损基准为本交易日首次取得的有效净值，不代表券商开盘净值；首次运行前的当日亏损尚未覆盖。基准、峰值和触发原因随状态持久化。STOP 文件触发停止新开、撤入场单和管理已核验组合退出；触发原因锁定，重启或删除 STOP 不应当作自动恢复交易。账户汇总 Greeks 限额仍未实现。

what-if 仍只在启动时查每组一单位，再按数量乘算；真实数量、已有重叠仓位和组合保证金抵扣未验证。可用资金会约束新增额度，并保守扣减本策略预留量，可能重复扣减已有保证金。须增加真实数量与当前账户仓位下的复核。真实账户字段与更新频率尚未在本次 IBKR 会话中验证。

验收：行情断流、购买力不足、风控触发时停止新开仓；退出失败持续报警。进程停止不表示平仓，必须核验券商成交和剩余持仓。

## 4. 数据与成交校准：仍无实盘证据

当前只有已取得的 SPY 分钟 NBBO，tick 历史接口被套餐拒绝。合成 BAG 价差、假设延迟及盘口数量分配均未用真实 BAG 成交校准；分钟数据无法验证 tick 退出顺序。窄价差情景不能当作真实成交改善。

需要记录同一时钟下的逐腿与 BAG 报价、发单、确认、成交、撤单时间，校准等待时间、成交率、部分成交率、价差和费用。校验时区、行情权限与延迟，缺数据时明确停用信号。

## 5. 策略有效性与美式期权风险

模型获利概率 >70% 和到期最大盈亏比 >1 是筛选条件；不证明日内实际胜率或正期望。需要多个交易日、不同波动环境、独立样本和参数敏感性验证，报告胜率不确定性、平均盈亏、净期望、回撤及无法平仓次数。

SPY 为美式期权；现有 Black 估值近似尚未覆盖提前行权、除息指派及指派后股票仓位处理。日内计划平仓不能保证断线或拒单时不会隔夜。须定义残余腿、股票风险和隔夜应急处理。

已通过离线故障与原生回放测试；当前没有连接 IBKR 或启动自动实盘委托。下一步为真实账户字段与数量保证金核验、paper 故障演练、经授权的最小规模成交校准及独立样本评估。Dash 交易台与调速回放见 [操作说明](../src/qwork/ui/terminal/README.md)。
