# Dash 期权交易台

使用 Dash、AG Grid、Plotly 和 FlexLayout 实现停靠式交易台；pywebview 使用 Windows Edge WebView2 显示。默认布局将期权链与组合风险并排，保留 MT5 预设，视觉参考 ATAS 深色主题。十四个面板可拖动停靠、调整尺寸和最大化，各工作区独立保存布局。

IV 默认二维热力图，可切换三维曲面及 Call / Put；到期日按实际日期分类显示。默认模式减少无 GPU 环境的资源占用。

## 启动

在工程根目录运行：

~~~powershell
./scripts/start.ps1
# 仅浏览器，默认端口 8766
.venv/Scripts/python.exe -m qwork terminal --no-gui
~~~

打开 http://127.0.0.1:8766 。启动不连接 IBKR、不启动 EA、不提交委托。端口已有本工程交易台时，桌面启动会打开现有服务，不启动重复节点。原有四个 Actor 分析界面仍可通过 `qwork dashboard` 打开。

## 布局与导航

默认左侧为期权链，同组标签可切换 K 线、市场报价、导航器、曲面和期限结构；右侧始终显示组合风险。底部工具箱集中持仓、委托、账户、净值、日志、测试器与 EA。Paper / LIVE 默认打开更高的 EA 控制区，回放打开测试器；研究打开持仓。

顶部“文件”菜单提供保存、恢复、“期权交易布局”和“MT5 默认布局”。已保存的自定义布局继续保留。导航器、菜单和工具栏只定位对应面板；“EA 管理”不会自动连接账户或启动策略。Ctrl+M / N / T / R 分别定位市场报价、导航器、持仓与测试器，F1 打开帮助，Esc 收起菜单；启动确认弹窗中停用视图快捷键。

ATAS 风格使用中性深灰、扁平标题、紧凑表格和弱网格，图表价格轴置于右侧；红绿 K 线、淡蓝选中态和淡金色最后历史报价线保留不同的视觉用途。图表与表格只展示已加载数据。`theme.py` 集中图表配色，`terminal.css` 管理控件外观；主题不改变账户、信号或委托。

参考：[MT5 界面](https://www.metatrader5.com/en/terminal/help/startworking/interface)、[ATAS 图表视觉设置](https://help.atas.net/en/support/solutions/articles/72000602496-visual-settings-of-the-chart)。未添加没有真实数据支持的盘口、Footprint 或成交量图。

默认布局全部面板保持挂载；恢复旧的折叠边栏布局时，先在不可见状态挂载，再通过 FlexLayout 动作折叠，以保持跨面板回调参数完整。

## 行情和 K 线

顶部明确选择研究、回放、Paper 或 LIVE 工作区。研究用于行情分析和报告；回放统一使用 SIM 账户、原生回放报价与历史时钟；交易工作区统一使用 IBKR 账户及实时快照。切换不会连接账户、启动策略或停止已经运行的策略，后台 EA 的账户和状态始终显示在顶部。LIVE 使用红色环境提示。

数据来源由工作区统一控制，各面板的来源标签仅显示状态。交易工作区不显示缓存历史期权链和历史 K 线；回放不使用旧 IV 曲面或不同日期 / 标的的图表。

左侧输入标的，展开“行情设置”选择模式、纽约日期与时间，再点击“刷新”。报价窗口显示所选到期日、行权价附近的真实期权 BID / ASK；它不是股票报价。实时模式调用 Theta 官方 SDK 和现有四个原生 Actor。期权链显示报价时间；展开“期权合约设置”调整到期日、行权价和方向。

单击报价窗口，或关闭期权链默认的“组合选腿”后单击 CALL / PUT 报价 / IV，完整合约与图表联动；点击行权价列沿用当前方向。工具栏 M1 / M5 / M15 / M30 / H1 切换实际历史聚合周期。K 线来自历史 NBBO 中点，不是成交 OHLC，也不是实时股票 K 线。纽约时间显示；活动回放只聚合已经回放的报价，包含尚未结束的当前 K 线。淡金色价格线表示最后一根已显示 K 线的中点收盘报价。

回放期权链只包含回测实际加载的合约，显示报价时间，不将旧 IV 当作当前 IV。

## 组合风险与期限结构

在研究工作区的“组合风险”面板选择候选并设置分析组数，原生 PortfolioPnLActor 计算当前模型情景与精确到期盈亏，TermStructureActor 计算按实际到期日显示的期限结构。选择后折叠候选列表，让风险图与逐腿成本优先显示；展开列表可换组合和数量。

首次缓存分析由原生 Actor 读取明确标记的历史快照，不自动访问数据源。刷新行情后使用正常原生数据链。买入腿以 ASK、卖出腿以 BID 作为分析建仓假设；该操作不建立持仓或委托。当前可平仓估值方向相反并扣预计费用。扫描列表包含其费用 / 滑点假设，到期曲线仅扣建仓佣金；缺报价时隐藏当前估值，保留到期曲线。模型概率不是历史胜率。

## 期权组合篮子

期权链工具栏可直接切换到期日、显示所选行权价附近 20 / 40 档或全部报价，并清除列筛选、导出当前筛选后的链 CSV。链中新增双边挂单量及价差，字段缺失时保留空值。

启用“组合选腿”，点击 Call / Put 报价，再加入买入腿或卖出腿。选腿模式保持在期权链；关闭后仍可点报价联动 K 线。买入按 ASK、卖出按 BID 预填每股成本，100 倍乘数由现有模型约束。更改工具栏组合名称可在同一篮子添加另一组。

打开“组合篮子”，双击表格修改组合名称、买卖方向、张数及每股成本；支持移除所选腿、清空草稿和设置每张单边佣金。点击“分析全部组合”复用原生 PortfolioPnLActor，再选择合计或单组合查看当前模型 / 到期盈亏及对应腿。最多 20 个同标的组合，每组 32 腿，可混合到期日。张数必须为正整数，成本必须非负；交易工作区拒绝使用历史曲面。报价缺失、不同到期日的静态情景和提前行权限制沿用 Actor 诊断。

篮子属于分析输入；它不创建委托，也不作为账户持仓。清空草稿保留已提交分析，应用新输入后才重新估值。单组视图直接使用 Actor 对应结果，不另算一套盈亏。

浏览器验收：`python tests/terminal_options_smoke.py`，记录 `data/verification/terminal-options-browser.json`。

## 数据版本、草稿与风险提示

每次原生曲面发布分配独立版本；扫描、组合估值及期限结构携带来源版本，旧任务不能覆盖新行情。结果显示自身报价时间；新行情到达而分析未完成时保留旧结果，标注等待重算。历史快照仍按研究日期分析。

实时分析同时检查采集状态、快照和逐腿报价年龄。快照有效期为 `max(10, 2 × refresh_seconds)` 秒，逐腿报价还允许采集时配置的 `max_quote_age_seconds`；时间缺失、异常、过期、暂停或采集失败时禁止应用分析。服务在线只代表本地界面响应，账户仍独立核验。

篮子直接显示选中合约、BID / ASK、腿数和加入结果；空白报价不能加入。AG Grid 保存草稿行，名称和佣金也保存；修改后必须点击“分析全部组合”。状态明确区分未应用修改与已应用分析，清空草稿保留已提交结果。桌面使用 `data/ui/webview/` 持久配置目录，重新打开不再使用临时隐私会话；不同浏览器仍有各自草稿。

链默认七列核心报价，可切换流动性或完整明细。表格占剩余高度，横向滚动条保持在面板内。盈亏图优先显示，纵轴按初始可见价格范围缩放；应用明细可折叠。

同日到期风险按所有行权价拐点和价格尾部计算最大盈亏、盈亏平衡点及无限风险，不由有限图表范围推断。金额扣建仓佣金，沿用 Actor 的到期收益模型；美式提前行权、指派费和融资不在其中。混合到期日只展示静态情景，不给出路径最大盈亏。

桌面 CSV 开启保存对话框并反馈保存完成、取消或下载中断；浏览器连续导出直接调用 AG Grid 导出 API。验证命令为 `python tests/terminal_review_smoke.py`、`python tests/terminal_desktop_export_smoke.py` 及后者的 `--cancel` 模式；桌面自动测试仅代选保存对话框结果，下载和文件写入使用真实 WebView2。

## 原生策略测试器

切换回放工作区，在“回测配置”设置独立的标的、日期、预算、并发组数和执行方式，再设置候选池及概率口径。修改这些参数不会修改 EA 表单或正在运行的 EA。默认日内概率仍严格要求 >70%，到期最大盈亏比 >1。到期概率选项只作研究对照。

研究回测共用订单管理，但尚未模拟 EA 的账户级亏损 / 回撤熔断、真实数量保证金与账户其他持仓影响。

速度可选 1 / 60 / 300 / 600 / 3600 倍或最大速度；暂停后才能单步推进一个原始报价时刻。按钮随空闲、准备、播放、暂停和停止请求状态启用 / 禁用。调速只改变等待时间，原生历史时钟、订单和成交计算不变。终止不会虚构平仓，未平仓会明确标错。

净值按当前模拟组合 BID 估值，成交和费用由 NT 记账。点击成交记录，在 K 线与净值图标记该时刻；这是检查定位，不倒退或重算原生时钟。报告保存于 `data/backtests/`，可载入和导出成交 CSV。旧报告没有净值快照时显示“现金余额”，不称为净值。

CSV 通过普通文件下载导出。新回测同时保留原生代理 `last_px` 和去除记账偏移的 `combo_premium`；原生报告不改写。

## 账户与 EA

持仓与委托提供标的、到期日、Call / Put、行权价、合约乘数和期权腿 / 回测组合类型。字段由 NT 原生合约读取，缺少原生信息时留空；原始账户数量和均价保持不变。回测代理组合继续按原有偏移规则显示净权利金。期权张数和组合组数不可混为股票股数，实际保证金仍以券商账户回报为准。

在 Paper 或 LIVE 工作区点击导航器的 EA 管理，输入 IBKR 账户编号并主动连接只读监看；该节点没有交易策略。连接参数读取工程 `.env`，密钥不会进入浏览器。EA 使用独立标的及参数，执行 / 风控可展开设置。“当前进程生效参数”和“EA 组合与委托进度”显示启动时的参数及组合生命周期，编辑表单不会更新运行中的进程。

收到新鲜的目标 USD 账户、净值及可用资金回报后，“审阅并启动 EA”才启用。审阅显示目标账户、标的、预算、执行和风险限制，有效期 90 秒；修改任一参数或工作区会禁用确认。LIVE 还须勾选本次真实委托确认。最终启动在服务端再次核验账户，审阅令牌只能使用一次。恢复核验与原生风险检查通过后才允许开仓；预算不是实际数量的券商保证金估算。

“停止开仓并平仓”写入该账户的持久 STOP 信号：停止新开、撤未成交开仓，并管理已核验组合的退出。界面显示停止请求、剩余意图单位和待确认委托；状态读取失败显示未知，不能当作零持仓。必须检查券商实际成交；进程运行或窗口关闭不代表已平仓。关闭交易台不会强杀策略进程。持久 STOP 会阻止新的启动审阅，不自动解除。

服务为本交易台新启动的策略原子保存进程身份和参数。重启时仅恢复唯一且可核验的后台进程监看；核验包含 PID、创建时间和完整启动参数，也记录 Windows venv 子进程。多个后台进程可选账户后点击“恢复此账户后台监看”。恢复只读监看不连接券商、不重启 EA、不发送委托；券商账户仍须主动连接核验。记录损坏或权限导致身份未知时阻止新启动；未登记的旧进程不会自动恢复。真实 IBKR 故障恢复仍待实测。

## 稳定性与连接状态

顶部显示本地服务连接状态；超过 4 秒无新快照提示变慢，超过 12 秒提示超时并显示数据冻结警告。超时时限制新的启动和取数操作，保留停止入口；服务恢复后提示自动清除。这里监测的是界面连接，不代表券商在线或停止已被执行，后台 EA 可能继续运行。

快速切换合约只保留一个运行中和一个最新待处理的 K 线任务，旧结果不会覆盖新选择。远程调用不能强行取消，关闭后丢弃其结果。读取锁定的策略 SQLite 状态约 50 ms 后报告未知，避免长时间阻塞界面；过期界面快照不发布空账户。分析 / 账户节点启动与关闭串行化，关闭后禁止新启动。稳定性验收范围见 [稳定性记录](../../../../docs/terminal-stability.md)。

## 模块边界与限制

`panels.py` 注册面板及初始布局，`workflow.py` 定义上下文与权限规则，`presentation.py` 定义风险图及成交检查，`app.py` 组装界面和回调，`backend.py` 管理隔离快照及作业，`reliability.py` 管理有界取数及进程身份，`desktop.py` 管理本地服务。停靠面板保持挂载，切换标签不丢失控件状态。节点构造、缓存读取、运行和释放在所属线程完成；前端只接收快照，不维护另一套成交账本。

轮询只向浏览器发送快照编号，面板在服务端读取相同版本，缓存有界；不把完整行情反复传回回调。图表数据未变化时不重绘。`/api/snapshot` 为回环地址只读诊断接口，仍执行来源检查。

`rendering.py` 通过每个浏览器独立的指纹去重：表格及说明文本只在内容变化时提交，账户变为空、切换来源仍会更新。K 线、净值和曲面隐藏时延后绘图，重新打开读取当前快照。分隔线拖动时显示位置预览，松开后调整图表；窗口缩放或标签切换结束后通过 Plotly 公开 API 校正画布尺寸，并限制图表绘制范围，减少裁切和残留。权限按钮仍每次核验，保留独立心跳和断线冻结。上述优化只影响显示，不降频原生策略、QuoteTick 或回测时钟。

`charts.py` 使用 Pandas 批量生成历史显示 K 线，复用一个报价来源和当前回放时钟的结果；在聚合前按时钟切片，未来报价无法改变当前部分 K 线，返回独立的显示行。Actor 状态在同一快照只读取一次；报告列表每五秒扫描，账户和行情轮询保持一秒。`python tests/terminal_profile.py --label after` 用本地真实期权缓存记录快照热点及不带 profiler 的计时，不联网取数。

渲染验收：`python tests/terminal_rendering_smoke.py --label after`。采集 12 秒空闲回调、浏览器长任务，反复切换面板、拖动分隔线并缩放到 1366×800 / 1680×1050，核对图表内部与容器尺寸。结果位于 `data/verification/terminal-rendering-after.json`；短时样本不能代表整日运行或所有 WebView2 / 显卡组合。

默认只监听回环地址并检查请求来源；不适合作为公网多用户服务。IBKR BAG 实盘成交、真实账户字段映射及故障恢复仍需券商环境验证。分钟数据、合成组合和假设盘口不能证明实盘胜率。见 [实盘验收](../../../../docs/live-readiness.md)。

浏览器交互验收运行 `python tests/terminal_workflow_smoke.py`；MT5 布局、ATAS 配色、菜单 / 快捷键 / 报价选图运行 `python tests/terminal_mt5_smoke.py`；断线与短时采样运行 `python tests/terminal_stability_smoke.py`；完整 SPY 回放验收运行 `python tests/terminal_smoke.py`。需要先启动本地服务及相应历史缓存，不连接券商或启动 EA。本机 8 GB 无分页空间，测试、回测与桌面窗口建议串行运行。
