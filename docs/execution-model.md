# 回放成交模型

回放使用 Nautilus 原生限价、撮合、延迟、手续费、订单、持仓和账户报告。组合仍由逐腿 NBBO 合成，以乘数 100 的线性记账代理回放；这些模型尚未经过真实 BAG 成交校准。

## 限价与退出流程

默认 `--execution passive` 在组合中点挂限价；`--entry-limit-fraction` 从中点到 ASK 调整，默认 0。触价概率默认 0，不自动假设中点成交。只有后续可观察的合成 ASK 到达限价且原生撮合允许，才产生买入成交；原生撮合记录实际价格。

开仓单默认等待 120 秒，撤单确认后冷却 60 秒，最多尝试 3 次。未成交可以重试；已成交的组合身份不能重复开仓。部分成交按实际数量管理，其余开仓数量先撤单。

退出保持市价委托。回放按有限 BID 数量分批退出，等待新报价处理余量，不生成更深盘口。原生 IOC 处理未成交部分；如果不能全部退出，报告明确失败。开仓超时、撤单确认、冷却重试和平仓限制通过共享 `OrderManagementConfig` 用于回放与 live；研究盘口、延迟和 IOC 分片只用于回放。券商订单路径仍待实际验证。

Dash 交易台按原始时间戳分组调用原生 `run(streaming=True)`，保留同一引擎与策略状态。最大速度、倍速、暂停和单步只控制墙钟等待；不修改历史时间或撮合。普通和分段 SPY 自然报价回放均为 -812.80 USD、清仓及审计通过。

## 盘口与假设

组合中点为两翼中点减两倍中间腿中点。组合半价差为各腿半价差加权和，乘 `--combo-spread-fraction`，再加四倍 `--leg-slippage`。默认价差系数 1、额外腿滑点 0；0.5 仅是价差收窄敏感性假设。每张每边佣金默认 0.65 USD。

有限顶层通过 L2 数据类型输入 NT，但来源仍是 L1 NBBO，**不是实际 L2 深度**。为防止不同组合重复使用共享腿，按固定候选池的腿数量比例分配盘口容量，不重新分配未使用容量；该保守分配也不是实际排队模型。仅在三腿时间戳完全一致时刷新组合盘口。默认 100 ms 延迟是假设；实际一分钟回放可能在一秒定时器上处理，报告等待时间以实际成交时间为准。

候选池只用 09:45 已知信息选取，各成交情景固定零额外腿滑点的选择参数。新研究与旧固定滑点研究的池和数量可能不同，不能把净亏损变化全部解释为成交改善。

## 运行与报告

```powershell
# 默认日内概率，挂中点
.venv/Scripts/python.exe -m qwork backtest --date 2026-10-02 --universe-size 6
# 到期概率对照，腿自然报价边界
.venv/Scripts/python.exe -m qwork backtest --date 2026-10-02 --universe-size 6 --probability-horizon expiration --execution natural
# 明确假设组合价差缩小一半
.venv/Scripts/python.exe -m qwork backtest --date 2026-10-02 --universe-size 6 --probability-horizon expiration --combo-spread-fraction 0.5
```

`report.json` 的 `execution` 标记未校准，`execution_summary` 区分提交数量、成交数量、取消和等待时间；零成交不能当作零风险盈利结果。`audit.json` 核对原始报价、限价、共享腿容量、费用、现金、预算和日内清仓。失败时命令返回非零退出码。

实际研究结果见本文件下方结果表。实盘缺口和验收见 [实盘接入缺口](live-readiness.md)。

## 2026-10-02 SPY 对照结果

保证金预算 10,000 USD，09:45 固定候选池 6 个，15:55 日内平仓，真实 Theta 1m NBBO。四个 v3 报告均通过 12 项逐笔与账户审计，全部清仓。

| 概率期限 / 成交情景 | 开仓委托 | 成交组合身份 / 数量 | 净盈亏 USD |
| --- | ---: | ---: | ---: |
| 默认日内 / 中点挂单 | 0 | 0 / 0 | 0 |
| 到期对照 / 中点挂单 | 18 | 0 / 0 | 0 |
| 到期对照 / 自然 ASK 开仓 | 3 | 3 / 49 | -812.80 |
| 到期对照 / 假设半价差、中点挂单 | 13 | 3 / 22 | -276.40 |

自然报价对照亏损归因为中点变动 -42.50、跨价差 -515.50、佣金 -254.80；没有额外固定腿滑点。半价差情景平均成交等待 120 秒，累计请求 174 组、成交 22 组（请求含重试），三个组合仍全亏损；3 USD 的报价步长舍入调整独立列入审计。

“默认没有合格信号”和“有信号但挂单未成交”分别记录，不能合并为策略无亏损。两种成交情景的数量、时点和组合身份不同，净盈亏不能当作同仓位的成本差。半价差未校准，不证明能在真实 BAG 达成。此前 -1,875 USD 研究使用不同固定滑点和候选池，保留作历史诊断。

原始报告目录为 `data/backtests/SPY-2026-10-02-{intraday,passive,natural,combo-half}-v3/`。`natural-v2` 未通过共享腿数量审计，只作诊断；v3 已修正。
