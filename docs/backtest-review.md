## 本次发现并修复的错误

15:55 的原生定时器先于该分钟行情更新触发，市价强平会立即使用缓存中的 15:54 组合 BBO。逐笔与原始报价对照确认该问题。修复后，研究回放等待当前合成 BBO 再发出市价单；待执行退出原因保留。实盘市价单仍交由经纪商执行，未改变为等待模型求解。

此前 -1,670 USD 的结果比修复后少计亏损 205 USD，已标为中间诊断结果。新增测试使用独立的数学价格，验证强平使用新报价而非旧报价。另验证本机 Nautilus 撤单 API 接受 ClientOrderId，原生挂单实际变为 CANCELED。

每次回放自动输出 `audit.json`，检查会话、成交因果顺序、逐腿 NBBO、佣金、盈亏拆分、共享腿数量、原生报告完整性、持仓盈亏、账户余额、平仓与保证金释放、入场阈值与去重、预算与并发数。审计失败标记 `failed_validation`，命令返回非零退出码。
